# يا مال الشام لتحويل العملات

بوت Telegram أولي لإدارة طلبات الصرف والإيداع والسحب يدوياً.

## إعداد Render
- أنشئ خدمة Worker (وليس Static Site أو Web Service).
- Build command: `pip install -r requirements.txt`
- Start command: `python bot.py`
- أضف متغيرات البيئة `BOT_TOKEN`, `CHANNEL_USERNAME`, `ADMIN_IDS`.
- استخدم قرصاً دائماً (Persistent Disk) لمسار قاعدة البيانات `/var/data/yamal.sqlite3`، وإلا قد تضيع بيانات SQLite عند إعادة النشر.

## أوامر الإدارة
- `/setrate USD SYP 15000` لتحديث سعر يدوي.
- `/review 12` لمراجعة طلب.
- `/approve 12` لاعتماد طلب بعد التحقق الخارجي.
- `/reject 12` لرفض طلب.

## ملاحظات مهمة قبل التشغيل الحقيقي
هذا إصدار تأسيسي/تجريبي، وليس نظام تحويل أموال مرخصاً أو تكاملاً مع شام كاش/سيريتل كاش/MTN/Binance. لا تعتمد عليه لحفظ أموال العملاء قبل مراجعة قانونية وأمنية واختبارات مستقلة. الطلبات لا تنفذ تلقائياً؛ يجب التحقق من وصول الأموال خارج البوت قبل الاعتماد. لا تضع Bot Token في GitHub أو في المحادثات.
